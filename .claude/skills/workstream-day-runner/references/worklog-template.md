# 워크로그 템플릿 — docs/dailyWorkLog/N_Day.md

완료 처리(4단계)의 **워크로그 작성** 단계에서 이 서식으로 `docs/dailyWorkLog/<N>_Day.md`를 만든다.
`완료 Task` 목록은 **다음 회차의 완료 집합 판정 근거**이므로 Task 번호를 정확히 적는다.
문체는 프로젝트 문서와 동일한 단정적 평서체, 날짜는 ISO(YYYY-MM-DD).

**주체는 사람이 아니라 업무 영역(워크스트림)이다.** 인물 이름을 적지 않는다.

---


## 완료 집합 재구성 규칙

다음 회차(1단계 2번)에서 팀장은 `docs/dailyWorkLog/`의 모든 `*_Day.md`에서 위
`## 워크스트림별 완료 내역`의 **완료 Task 번호**를 모아 완료 집합을 만든다. 그래서 이 섹션의
Task 번호 표기는 반드시 `docs/ROADMAP/work/`의 배정 단위 표기와 동일해야 한다. **쪼갠 Task는
조각 ID로 적는다**(`008` ✕ → `008A`·`008B` ○) — 완료 집합 판정도 조각 단위로 이뤄지고,
원 번호는 모든 조각이 모여야 완료로 접힌다(SKILL.md 1절 3번).
