## 교차검증 결과

- 크롤 파이프라인 → 저장소 계층(Task 006): 1차 pass + 결정 필요 1건 + 보완 1건. DoD 5개·함정 항목(sourceType
  전환 시 잡종 레코드 방지, 기본 불용어 7건, id 불변)·규약 전부 통과. 슬러그 문제는 리뷰어가 **2안(로마자
  라이브러리)을 기각하고 3안을 권고**했다 — "블로터"를 음역하면 `beulroteo`가 나오지 후보 문서에 이미 못 박힌
  `bloter`가 나오지 않는다는 근거였다. 수정 후 재검증 pass — `id` 필드가 생기면서 불변 규칙이 뚫릴 수 있는
  자리를 `updatePress`의 두 분기 모두에서 확인했고, 013B가 쓸 후보 id 5건이 새 형식을 전부 통과함도 대조했다.
- 화면 → 크롤 파이프라인(Task 007): pass + 테스트 공백 2건. DoD 5개·함정 항목 전부 통과. `listArticles`가
  `fs.open` + 위치 지정 부분 읽기로 본문을 읽지 않는 것을 코드로 확인했다. 개행 처리 모순은 리뷰어가 화면
  설계서까지 대조해 담당 해석이 맞다고 판정했다. 공백 2건(contentSource 라인 누락, URL 개행)은 보완 완료.
