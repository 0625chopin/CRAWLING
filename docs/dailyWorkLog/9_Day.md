### 실측 검증 (dev 서버 실동선)

원 Task 015 DoD를 실제 서버(포트 3001)에 태운 결과다. **016A가 아직 없어 폴링하는 화면이 존재하지
않으므로**, `browser_network_requests`로 볼 대상 자체가 없다. 브라우저 대신 HTTP 요청으로 같은 흐름을
직접 태웠고, **화면이 붙는 016A·016B 회차에 브라우저로 다시 확인해야 한다.**

- **① 202 + `runId` + 그 시점에 `run-meta.json` 존재** — `POST /api/crawl` `{pressIds: 4곳,
  maxArticlesPerPress: 30}` → `HTTP 202` `{"runId":"20260810-210125"}`. 곧바로
  `data/runs/20260810-210125/run-meta.json`이 `status: "running"`·`finishedAt: null`로 존재함을 확인.
- **② 1초 간격 호출 시 진행률·언론사별 상태 갱신** — `GET /api/crawl/{runId}` 반복 호출에서
  `overallPercent`가 `53 → 97 → 100`으로, `currentPressName`이 `ZDNet 코리아 → 아이뉴스24`로 실제 변했다.
- **③ 비활성 언론사 id 400** — `naver-d2`(`isActive: false`)를 섞어 POST →
  `HTTP 400` `비활성이거나 존재하지 않는 언론사입니다: naver-d2`.
- **④ 실행 중 재 POST 409** — `HTTP 409` `이미 실행 중인 작업이 있습니다: 20260810-210125`.
- **⑤ 중단** — 진행 중 `POST /api/crawl/{runId}/abort` → `HTTP 200`. 이미 시작한 언론사가 끝난 뒤
  `run-meta.json`이 `status: "aborted"`가 되고 **기사 txt 51건이 그대로 보존**됐다.
- **없는 runId abort 404 / 끝난 run abort 409** — 각각 `실행을 찾을 수 없습니다: no-such-run`,
  `이미 종료된 실행은 중단할 수 없습니다: 20260810-204838`.

**8일차에서 이월된 014B DoD ④⑤의 라이브 확인도 여기서 닫혔다.** 8일차 검증은 전부 mock 기반이었고
"실크롤 [중단]"과 "수집분 보존"은 015A가 없어 태울 수 없었다. 이번에 실제로 4곳 크롤을 걸고 중단해
`aborted` + 51건 보존을 파일로 확인했다.

**검증용 run 3건을 지우지 않고 남겼다** — 10일차 Task 017(수집 결과 조회 API)이 읽을 실제 데이터가

   그리면 **중단 버튼을 눌렀을 뿐인데 "실패 43건" destructive Alert**가 뜬다. 016B 착수 전에 닫아야 한다
